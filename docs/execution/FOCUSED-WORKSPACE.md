# 单窗口工作区

范围：前端信息架构、白灰极简界面与交互；不修改既有纸面编辑器或后端资料/分析契约。

| 模块 | 选择与内容 | 固定操作 |
| --- | --- | --- |
| 今天 | 最近行动，三个直接入口 | 添加岗位、编辑简历、记录工作 |
| 岗位推进 | 岗位列表 → 岗位/评估/研究/简历/沟通/面试/Offer | 更新下一步、对应模块动作、岗位管理菜单 |
| 我的材料 | 个人资料/简历版本/早期记录 | 保存当前资料、打开独立编辑器 |
| 工作阶段 | 工作卡 → 事项/协作/收获 | 编辑工作卡、导出阶段、按类别记录 |
| 练习与收获/足迹 | 记录列表 → 单条原文与所属任务 | 返回对应岗位/工作 |
| 反馈 | 反馈列表 → 原话和补充 | 记录、补充、导出 |

允许修改 frontend/src/main.ts、frontend/src/workspace.ts、frontend/src/style.css、frontend/README.md 和本批次/所属产品文档。主控执行；一个 Sol medium 只读审查。

验收：实际浏览器检查桌面/紧凑视口无 document 溢出，侧栏收起恢复，资料草稿跨导航保留，岗位分区及计划保存、工作分区与记录保存、嵌套反馈不中断输入，独立编辑器入口；typecheck/build。数据使用隔离虚构目录。真实 AI 未配置，不以预设结果代替。

状态与证据见下文。

## 实施与验证（2026-09-14）

已实现：白灰侧栏、收起/展开、底部本地菜单；岗位列表与七个业务分区；工作卡与事务/协作/收获；材料页分离个人资料、独立编辑器版本与早期记录；反馈、足迹与复盘采用列表/阅读区。窄详情区用记录选择器释放正文空间。所有新增记录仍调用本地 API；未引入预设 AI 输出。旧 action/reflection/interview 记录按实际存在显示兼容入口。

主控真实浏览器验证使用 `http://127.0.0.1:8766` 与 `/tmp/career-task-workspace-check`，不修改正式数据：

- 1280×720、1024×640、1440×900 下 document 尺寸等于 viewport。当前实际 791×771 窗口逐一检查六个一级页面，均无 document 溢出；窄布局记录选择器切换成功。
- 100 行研究记录在 1024×640 中阅读区高 336px、内容高 2824px。实际滚动后阅读区 scrollTop=1746.5、document scrollTop=0；记录按钮 top=251px 保持不变。
- 个人资料输入 → 收起/展开侧栏 → 岗位页 → 返回资料，原文完整保留且显示未保存；保存回显 v1。
- 下一步填写动作与日期 → 嵌套反馈 → 保存反馈 → 返回原弹窗，字段未丢失；下一步实际保存并在任务头回显。
- 实际 API 并发修改计划 → 浏览器保存得到 409 → 比较两份内容 → 人工合并 → 保存成功。
- 工作卡协作分区创建记录，回显原文且归属正确；历史工作期面试从练习页来源链接返回对应工作卡并选中原记录。
- 首页新建工作卡后地址为 `#work/<id>`，新开页面和同页 hash 链接均实际验证选中该卡；独立简历入口实际在同一 tab 打开 `/editor.html`，纸面编辑器主控件可见。
