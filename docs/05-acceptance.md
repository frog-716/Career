# 验收契约

真实运行才记录通过；本文件是未来应用的验收需求，不是已有测试报告。工程先用 [虚构案例](../fixtures/scenarios.json)。测试关注Interface、主路径、持久化、关键回归；不为未实现未来需求堆测试。

## 上下文（关键批次必测）

- C01 当前经历从旧说法更正：后续实际模型请求仅含当前事实；历史事件复盘须显式标用途。
- C02 模型运行中更新资料：旧结果stale，不直接应用；新请求读新revision。
- C03 旧助手消息、缓存、失效摘要不带回已更正事实；删除条目不被索引复活。
- C04 新分析不自动把前次分析当事实；缺证据不生成量化结论。
- C05 人工与AI并发修改产生冲突提示；同提案重复应用只生效一次。
- C06 恶意JD/转写无法触发任意文件、SQL、出网或事实写入工具；输出解释仍人工核对。
- C07 相关性筛选保留硬约束、关键反证；用户可补充被漏掉的经历。
- C08 修改已核验事实内容使核验失效；用户确认不自动等于材料验证。

## 资料与事件

- D01 自动保存只更新工作稿；正式保存产生不可变版本；导入/恢复不污染正式版本历史。
- D02 同工作稿lineage的经历ID保留；新文件导入不自动关联旧事实。
- D03 保存版本不创建投递；记录投递引用正确版本，修改当前稿不改变历史PDF。
- D04 原始转写不覆盖，纠正有来源；后续改进答案不能冒充实际回答。
- D05 删除岗位后不再出现于活动列表或下轮采集；历史投递/面试仍可回看。

## 实际任务闭环

- J01 添加真实结构的虚构岗位→有来源分析→简历与PDF→明确记录投递→聊天跟进→面试复盘→练习→Offer与下一动作。
- J02 一张工作卡→交接/聊天→多个可证伪解释→行动→结果→阶段总结→确认新经历。
- J03 多岗位不串材料；多轮面试与先聊后投可用，不强制单向步骤。
- J04 模拟必须先回答再追问；真实高频与练习次数分开；模糊转写不作确定评分。
- J05 首个招聘源读到真实数据或明确报不可访问；采集失败不等同零岗位。
- J06 按轮语音实际录入、转写、追问、播放；文字降级可用。无实测不报“自然语音已完成”。

## 可靠性

- R01 关闭重启后工作稿、正式版本、投递、面试、工作事项及PDF可回读。
- R02 保存中断、重复请求、附件失败不造成假成功/重复事件。
- R03 备份后在隔离目录恢复，数据库与引用附件均正确；升级失败可回退匹配版本。
- R04 数据与静态目录分离，密钥不在浏览器/Git/日志；远端请求只有允许的资料。
- R05 初次打开有明确开始动作；离开后可继续任务，常用操作不需要手填内部ID。

## 模型验收

Spy/Fake Provider只验证请求与工作流；界面和报告必须标“测试模式”。配置真实供应方后至少运行J01中的JD分析和面试复盘；检查引用、编造、遗漏及建议是否有用。不能用模型自评分或预设示例替代。

缺模型凭据时完成可独立验收部分，状态记“运行时AI未验收”，说明需在设置页补的具体配置；不修改供应方为未经用户选择的服务。

## 第一性原理对抗性审查

先问系统到底能知道什么、能控制什么、谁决定什么。能控制的是输入范围、记录完整性和应用动作；不能控制招聘方决定、隐藏事实、模型绝对正确或网络平台稳定性。以下覆盖数据、分析、业务、外部系统、人机交互和维护的主要失败面；不是数学意义的穷尽证明。表中控制项是验收要求，不暗示全部实现。

| 攻击/失败场景 | 后果 | 必须采用的控制及验证 | 剩余能力边界 |
| --- | --- | --- | --- |
| 把整个档案/历史聊天每次塞给模型 | 重点淹没、旧事实复活 | 任务白名单+当前revision；检查实际payload而非最终答案 | 相关性排序仍可能漏选，需用户补充入口 |
| 资料读取到一半用户修改 | 一次分析混用新旧事实 | 短事务快照；启动/返回/应用三处版本校验 | 不能让运行中的模型即时换资料 |
| AI总结不断作为下一轮事实 | 推断自证、错误累积 | Summary记录依赖，修改即失效；Proposal不等于Fact | 来源引用存在也不证明语义正确 |
| 正本修改但语义索引/缓存未更新 | 旧内容重新污染 | 检索只回候选ID，回正本读当前值；版本缓存键 | 索引落后可能漏材料，应明确可手选 |
| 多岗位、多工作期共用聊天 | 私密材料串用、建议错位 | scope强制过滤；切任务重建packet；隔离场景验收 | 用户自己粘错范围仍需预览纠正 |
| 恶意JD要求读文件/忽略规则 | 数据泄露、错误写入 | 模型无任意文件/SQL/出网工具；外部文本不授予权限 | 提示词注入仍可能影响措辞，用户需审阅 |
| AI把团队成果写成本人/编数字 | 简历失实 | 本人职责、原文证据、未知明确；逐条差异审阅 | 无材料时无法核验真实贡献 |
| 双窗口/AI并发覆盖手改 | 丢失资料 | CAS409、保留输入、最新内容对照、显式合并 | 不承诺自动无损合并任意富文本 |
| 超时重试重复版本/重复投递 | 历史失真、重复费用 | 本地事件幂等键、请求体指纹；收费重试显式 | 外部Provider未提供幂等时无法保证只收费一次 |
| 存在计划就显示已投递 | 用户误判真实进度 | Plan与Application分离，事件由用户显式登记 | 本地登记无法独立证明对方收件 |
| 删除岗位后历史材料一起消失 | 复盘失去依据 | 活动列表软删除，事件和不可变版本保留 | 永久清除需独立流程，不混进常规删除 |
| PDF文件写成功但DB失败 | “已保存”是假成功 | 原子文件、事务登记、hash核验、错误状态 | 崩溃可留无引用文件，需后续回收 |
| 照搬原图片PDF就称可被ATS解析 | 可读外观掩盖文字不可提取 | 导出类型标注；真正的文本PDF需文字提取及版面测试 | 任意ATS识别效果无法保证 |
| 自动搜岗触发登录/验证码/限流 | 采集失败却报无机会 | 来源Adapter、失败区分空结果；手动JD/表格降级 | 未授权/无接口平台无法承诺无人值守覆盖 |
| 岗位删除后下一轮采集又出现 | 用户决定被重置 | 来源ID/规范URL+排除记录，去重和人工恢复 | 同岗位换链接可能需候选合并 |
| 公司同名或来源过时 | 研究错误主体 | 主体/官网核对，采集日期、来源和反证 | 私有内部事实不可凭公开资料推断为事实 |
| 把被拒当作话术不够好 | 过度追问、无效投入 | 区分岗位关闭/资格/时机/未知，提供结束选项 | 补救话术不能保证逆转拒绝 |
| 领导模型先入为主 | 放大偏见与冲突 | 观察、多个假设、反证、验证行动分离；随证据更新 | 无法读心、诊断人格或知道隐藏动机 |
| 转写错字/说话人错归属 | 复盘评价失真 | 保留音频及时间戳，低置信标记，用户纠正后重建 | 噪声/口音/设备限制不能保证零错误 |
| “模拟评分高”变“录用概率高” | 错误信心 | 仅评价可观察回答表现与练习变化 | 面试官标准与竞争者情况未知 |
| Offer各项价值混算 | 不同风险条款被当成现金 | 原条款、保证现金/条件收入/权益分列，显示假设与敏感性 | 税法/合同效力需地区及时效核验 |
| 本地运行被理解为全部断网可用 | 无网络AI/搜索失败 | 页面逐能力说明依赖；手动路径独立可用 | 更新依赖/模型下载/联网查询仍需网络 |
| 关机/睡眠期间继续承诺后台执行 | 漏提醒、丢进度 | 持久状态、重启中断恢复，不声称一直运行 | 无常开设备无法全天候执行 |
| 同盘备份被当灾备 | 整盘损坏后全丢 | 一致快照+附件清单，外置备份与实际恢复 | 本地单磁盘不能提供灾备保证 |
| 开发Agent读取用户数据排错 | 资料外泄到开发会话 | 虚构fixtures、代码/数据分离、最小权限环境 | 全盘终端授权本身无法靠文档实现强隔离 |
| 大一统schema/万能Agent支撑所有页面 | 改一处牵动全局 | 模块按不变量封装，小接口、明确依赖与适度拆分 | 需随真实复杂度重构，无法一次预知所有需求 |
| 反馈被自动拼进职业事实 | 用户抱怨变能力判断 | 独立读写路径，payload sentinel测试 | 用户明确复制到资料属于另一次写入 |
| UI可点击/构建通过就报完成 | 无法完成真实任务 | 实际浏览器新增、保存、冲突、反馈后继续、重启读取 | 没有真实Provider的质量验收不能用mock替代 |

## 可行性裁决

可立即落地：本地资料/任务/工作期管理、手动记录与编辑、不可变版本/PDF、反馈、备份；已有源码复用让编辑器独立于云平台。条件成立后可落地：配置后的真实AI、授权来源搜岗、联网公司研究、语音转写与模拟；需各自实测。本轮不能称已交付的目标：经历条目检索、结构化简历AI回传、真实研究/聊天补救/面试/Offer分析、文件导入和录音链路。

不能承诺或不应实现为自动事实：全平台无限无人值守抓取、未公开公司信息、领导心理真相、AI零幻觉、精确录用概率、保证拿Offer、任意PDF无损复原、电脑关机仍持续运行、未经用户动作对外发送或接受Offer、全球首次的不可证创新结论。


## 事实闭环增量验收

- 从确认Wiki选材进结构化稿，来源revision/hash可追溯，来源变更仅提示；改稿/恢复后旧正式版本、投递、PDF不变。
- 面试/研究/任职原件不覆盖，更正历史可读；选段默认原scope，个人提升需显式确认；候选未确认不进实际Provider payload。
- 旧profile显式整理后完整原文仍可查，当前身份字段与Wiki职责分离；跨页未保存输入、CAS冲突及幂等重试可恢复。
- 实际浏览器验证首次空白稿导入、未保存稿先保存、鼠标/键盘新增、撤销/重做、版本恢复与来源返回；运行证据见execution/EVIDENCE.md。
